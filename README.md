# CleanSSC（SSC存档清理 \+ 智能活跃备份）

**作者**：羽学、唉唉有

**开源地址**：https://github.com/Aiaiyou1/SSCManager

**插件适配**：TShock Terraria SSC服务器

**当前版本**：v1\.1\.0

---

## 📖 项目介绍

**CleanSSC** 是专为 Terraria SSC（服务器角色）服务器打造的轻量化管理插件。

解决 SSC 服务器长期运行积累大量**死档、过期玩家数据**导致数据库臃肿、卡顿、冗余问题；

附带**仅活跃玩家智能备份系统**，不备份长期离线死档，大幅节省服务器硬盘空间。

适合长期开服、多人在线、需要定期清理无效存档的 SSC 公益/商业服务器。

---

## ✨ 核心功能

### 1\. 自动清理长期未登录 SSC 角色

- 根据用户 `LastAccessed` 最后登录时间判定过期账号

- 自动导出过期角色 `.plr` 存档备份后，删除数据库无效角色数据

- 在线玩家**绝对不会被清理**，安全稳定

- 可自定义检测周期、过期判定分钟数

### 2\. 智能活跃玩家自动备份（特色功能）

- **区别于全量备份**：只备份近期活跃玩家，跳过长期离线死档

- 自动备份：玩家存档 \+ 世界地图 \+ tshock\.sqlite 数据库

- 独立时间戳备份文件夹，不覆盖、不乱档

- 自动清理过期备份包，自定义保留天数

- 后台线程静默执行，不卡顿服务器主线程

### 3\. 完善的后台指令管理

管理员可随时手动触发备份、开关自动备份、修改配置参数，无需重启服务器。

---

## 🎮 管理员指令

权限：`backup.admin`

|指令|功能说明|
|---|---|
|`/backup run`|立即手动执行一次完整备份|
|`/backup on`|开启自动备份线程|
|`/backup off`|关闭自动备份线程|
|`/backup min 数值`|设置自动备份间隔（分钟）|
|`/backup keep 数值`|设置备份文件保留天数|
|`/backup active 数值`|设置「活跃玩家」判定时长（分钟）|

## ⚙️ 配置说明

配置文件自动生成于：`TShock/SSCManager.json`

- **清理开关**：是否开启定时过期存档清理

- **清理判定时间**：超过多久未登录判定为过期死档

- **备份总开关**：全局启停自动备份

- **备份间隔**：定时自动备份周期

- **备份保留天数**：自动删除超时旧备份

- **活跃玩家判定**：仅该时间内登录的玩家才会被备份

- **备份世界/数据库开关**：可单独关闭不需要的备份项

## 📁 目录结构

- `TShock/SSCBackups/` —— 自动备份存放根目录（按时间戳分文件夹）

- `TShock/SSCExpiredExport/` —— 被清理的过期玩家存档备份目录

## ✅ 优势特点

- **纯SSC适配**：不读取本地plr，完全读写TShock数据库角色数据

- **零卡死**：后台线程运行，不占用服务器主线程

- **智能过滤**：跳过空数据、解析失败、长期离线玩家

- **安全释放**：支持热重载、优雅关闭，无 `Thread.Abort` 报错

- **不依赖第三方插件**：独立运行，不绑定FixTool

---

## 📌 适用场景

- SSC长期服，数据库越来越臃肿

- 不想备份几万个僵尸死档浪费硬盘

- 需要定时轻量化、安全备份活跃玩家数据

- 需要自动清理无效角色，提升服务器流畅度
